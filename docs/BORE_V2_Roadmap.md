# BORE v2 Roadmap (Next Development Sprint)

## Vision

BORE is **not a chatbot**. BORE is the **Resident Intelligence** of the
Out of Boredom portfolio. It should feel alive, observant, memorable,
and genuinely useful.

## Priority 1 -- Knowledge Engine

-   Answer using the full project object, not just titles.
-   Explain technologies, datasets, architecture, goals, challenges,
    GitHub, and business value.
-   Pipeline:
    -   User Question
    -   Intent Detection
    -   Relevant Project
    -   Complete Project Object
    -   Response Builder
    -   Natural Response

## Priority 2 -- Idle Behaviour

-   Add timed idle observations.
-   Reset timer after user interaction.
-   Randomize messages.
-   Avoid spam.

Example ideas: - "Still here? Humans usually leave after twenty
seconds." - "There are six projects. Nobody starts with the sixth."

## Priority 3 -- Hover Awareness

React to hovered UI elements. Examples: - View Projects → "They're
finally looking at the interesting part." - GitHub → "The source code.
Otherwise known as the crime scene." - Profile → "Credentials. Humans
seem to enjoy those."

## Priority 4 -- Hero Section

-   Large animated BORE skull.
-   Breathing animation.
-   Eye blink.
-   Floating motion.
-   Ambient particles.

## Priority 5 -- Consistent Identity

Use `/public/bore/bore-face0.png` everywhere: - Floating button - Chat
header - Typing indicator - Hero artwork

## Priority 6 -- Better Responses

Increase response variety. Mix intelligence with occasional dry humor
instead of repeating the same templates.

## Priority 7 -- Conversation Memory

Remember recent questions and projects so follow-up questions work
naturally.

## Priority 8 -- Page Awareness

Know the active page: - Home - Projects - Individual Project - Profile -
Contact

## Priority 9 -- Personality

Target balance: - 80% Intelligent - 15% Bored - 5% Savage

## Priority 10 -- Living Website

Narrate the portfolio. Examples: - Home: "Curiosity brought you here." -
Projects: "One project gets most of the attention." - Profile:
"Credentials. The traditional human ritual."

## UI Improvements

-   Smaller BoreWindow.
-   Only messages scroll.
-   Floating assistant on every page.
-   Preserve chat state between pages.
-   Responsive layout.

## Long-Term Goal

Build a portfolio that feels inhabited by an intelligent resident rather
than embedding a conventional chatbot.
